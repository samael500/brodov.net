# Карты «Бродов нет»

Первая рабочая версия генератора: GPX + JSON → PNG и SVG. Геометрия берётся из GPX и OpenStreetMap, а не генерируется нейросетью. Подложка приглушённая, края растворяются в бумаге, трек и подписи чёткие. Зернистость не добавлена: для статьи достаточно фактуры самой страницы.

Утверждённые правила оформления полной карты и миниатюры: [контекст проекта](../../docs/PROJECT-CONTEXT.md#карты-маршрутов--утверждённые-правила). Для новых маршрутов использовать их как образец.

## Быстрый запуск

Python 3.10+:

Из корня репозитория:

```sh
make route-setup                 # один раз: отдельное Python-окружение
make route                      # Русская тропа, без сетевых запросов
make route ROUTE=another-race    # route-sources/another-race/route.json
```

Исходники и кэш: `route-sources/russian-trail/`. Готовые PNG/SVG:
`content/posts/russian-trail/route.png` и `route.svg`. Обычная сборка Hugo
использует готовые файлы и не требует Python-зависимостей генератора или Overpass.
GPX и кэш не попадают в сайт, но будут видны в исходниках при публикации Git-репозитория.

## Другой забег

Создать отдельную папку с track.gpx и route.json, например:

```json
{
  "gpx": "track.gpx",
  "title": "Название забега",
  "subtitle": "Место · дата · официальная дистанция · результат",
  "cache": "cache",
  "output": "output/route",
  "marker_every_km": 20,
  "elevation_gaps": []
}
```

```sh
tools/route-generator/.venv/bin/python tools/route-generator/render.py path/to/route.json --fetch
tools/route-generator/.venv/bin/python tools/route-generator/render.py path/to/route.json
```

Первый запуск получает контуры OSM, дальнейшие используют кэш. Пути в JSON относительно самого JSON. Кэш привязан к SHA-256 GPX: нельзя случайно отрисовать новый трек поверх старого района. При недоступности Overpass генератор выдаёт ошибку; не заменяет географию выдуманной. Можно задать overpass_endpoint для другого совместимого сервера. --fetch обновляет кэш; не вызывать его при каждой сборке Hugo.

## Высота и дистанция

Сумма расстояний рассчитана по координатам на сфере; это не официальный результат и не обязательно совпадает с приложением часов. Официальные данные вводятся в subtitle вручную. Набор высоты автоматически не считается: барометрические ошибки делают наивное суммирование ненадёжным.

Пропуски высоты задаются явно в километрах по GPX:

```json
"elevation_gaps": [{"from_km": 9.42284, "to_km": 10.67403}],
"gap_note": "Пунктир — пропуск подводных показаний, не восстановленный рельеф."
```

Это настройка конкретного трека, а не автоматическое обнаружение бродов. Для Русской тропы интервал охватывает очевидную барометрическую аномалию: точные границы погружения из GPX неизвестны. Пунктир связывает соседние доступные значения, но не заявляет восстановление истинного рельефа. Исходный GPX не изменяется. Пульс и время из GPX не визуализируются.

## Ограничения первой версии

- GPX 1.1, один непустой trkseg; несколько сегментов отклоняются, чтобы не рисовать выдуманные соединения.
- Требуются координаты и хотя бы часть высот; при отсутствии всех высот выводится ошибка.
- Локальная равнопромежуточная проекция, север сверху, широта до 85°, протяжённость в пределах 5° по каждой координате. Не предназначена для пересечения линии смены дат или мировых маршрутов.
- Старт и финиш в пределах 200 м объединяются; иначе выводятся отдельно.
- Контуры OSM поддерживают замкнутые ways и составные outer/inner rings. Незамкнутые части пропускаются; подложка зависит от полноты данных OSM. Вложенные relation не раскрываются рекурсивно.
- Подписи населённых пунктов разрежаются простой эвристикой: новый район нужно визуально проверить на пересечения названий и трека.
- Длинное название/подзаголовок может потребовать изменения компоновки.
- SVG содержит растровую маску мягких краёв. Это нормально для воспроизводимой статичной иллюстрации.
- Заголовок — локальная Literata, служебные подписи — локальный PT Sans из `assets/fonts/` проекта. Лицензии сохранены в `static/fonts/`.

## Картинка анонса

Необязательное поле `preview_output` в JSON задаёт путь PNG для главной,
относительно JSON. Например: `../../content/posts/russian-trail/route-preview.png`.
`make route` создаёт его вместе с полной картой: та же геометрия и подложка,
без заголовка, профиля и мелких подписей; атрибуция OSM сохранена.
В статье этот файл выбирается отдельно через `preview_image` и `preview_image_alt`.

Толщина маршрута в миниатюре — **2.5 pt**, в полной карте — **1.8 pt**.
Это утверждённые независимые настройки: усиление миниатюры не должно менять
карту внутри статьи. На главной картинка ограничена высотой 260 px без обрезки.
