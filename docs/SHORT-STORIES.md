# «А что за поворотом»

Постоянные фотоистории, не исчезающие Stories. Название без вопросительного
знака. Рубрика охватывает жизнь, путешествия, бег, кухню и увлечения.
Фото остаются фотографиями; акварель не применяется автоматически.

Основание: HANDOFF.md, BLOG-RULES.md, MEDIA-WORKFLOW.md и TELEGRAM-IMPORT.md
из переданного автором `brodov-around-the-bend.zip` (19.09.2026).
Исходный автономный макет извлечён рядом с репозиторием в
`../blog-preview/around-the-bend-reference/`. Его Unsplash-фотографии и
вымышленные подписи не используются в блоге.

## Хранение и хронология

Одна история — `content/shorts/<slug>/index.md` и выбранные медиа рядом.
Поддерживается JSON, YAML или TOML front matter. Импорт пишет JSON,
который Hugo читает штатно. Дата со смещением часового пояса обязательна
для импорта. Ручные даты без смещения трактуются как Europe/Moscow.

Перед Hugo запускается `tools/stories/content.py`: читает front matter,
проверяет кадры и создаёт месячные разделы в игнорируемой
`.shorts-generated/`. Этот каталог подключён вторым content mount.
Не редактировать его вручную. `make build`, `make check`, `make preview`
и `make dev` выполняют подготовку автоматически. При добавлении или
смене даты истории во время `make dev` перезапустить команду, чтобы
обновить месячные разделы. Для независимого запуска Hugo сначала вызвать
`python3 tools/stories/content.py` (или `--preview`).

Часовой пояс группировки фиксирован: Europe/Moscow, независимо от CI.
Ключ месяца включает год. Названия месяцев — явный русский список,
не системная locale. Пустых месячных блоков нет. Дата блока — последняя
дата его доступных историй. Главная объединяет статьи и месячные разделы,
сортирует по дате, при равенстве — по типу и пути, и только затем
пагинирует (10 элементов; раньше пагинации в проекте не было).
Одна история не получает одновременно самостоятельный анонс на главной.

В карусели до восьми последних историй месяца; при превышении лимита
есть дополнительная ссылка «Весь [месяц]». Счётчик показывает все истории,
с русским склонением. Порядок историй: новые сначала, при равной дате —
путь по возрастанию. Архивы: `/shorts/`, `/shorts/YYYY/`, `/shorts/YYYY/MM/`.
Полный месяц пагинируется по 10 историй.

Черновики видны только с `--buildDrafts` в preview. Будущие даты,
будущий publishDate и прошедший expiryDate исключены из месячных блоков.
Production не содержит страниц, медиа, RSS и sitemap скрытых историй.
Нет общего клиентского manifest с приватными кадрами. RSS содержит
каждую историю один раз, с подписью, небольшим изображением и permalink;
месячные разделы не дублируют их.

## Интерфейс

Существующие шрифты Literata/PT Sans и фон #FAF8F3 сохраняются.
Обложки примерно 3:4, 164px (142–164px на телефоне, с видимым продолжением ленты), радиус 15–18px.
Кадрируется только обложка; `cover.position` управляет CSS object-position.
Производные обложек 320/640px по ширине, без увеличения маленького исходника.
Полные кадры 960/1600px по длинной стороне, `object-fit: contain`.

Карусель: scroll-snap, свайп и тачпад, стрелки 44px, виден следующий кадр;
вертикальное колесо не перехватывается. Стрелки выключаются у краёв,
при одной истории скрыты. Автопрокрутки и бесконечного клонирования нет.

Карточка — обычная ссылка. JavaScript открывает нативный `dialog`:
фон блокируется, фокус ограничен диалогом; Escape/Back закрывают,
возвращаются исходная прокрутка и фокус. Forward снова открывает историю.
При переходе между историями URL обновляется; прямой permalink работает.
Внутри: стрелки, клавиши, горизонтальный свайп, индикаторы кадров.
Навигация ограничена тем же месяцем, переход за его пределы отсутствует.
Без JavaScript доступны все кадры с подписями и ссылки на соседние истории.

Загружается текущий кадр; уже просмотренный сосед может остаться в DOM,
остальные кадры находятся в inert template. Не скачивается весь месяц.
Подписи не обрезаются, длинная подпись прокручивается вместе с просмотром.
Видео: controls, playsinline, preload=none, poster, без autoplay;
перелистывание и закрытие ставят видео на паузу. Жесты на controls видео
не перехватываются.

## Локальный предпросмотр и проверки

```sh
make stories-setup
make stories-test
make preview
PYTHONPATH=tools python3 -m stories.demo
python3 -m http.server 8766 --bind 127.0.0.1 --directory ../blog-preview/around-the-bend-site/preview
```

Последние две команды создают отдельный сайт **вне репозитория** с
явно обозначенными тестовыми черновиками на существующих материалах
блога и синтетическим видео. Там показаны 12 историй в одном месяце,
одиночные месяцы, разные годы, перемежение со статьями, портрет,
горизонтальный кадр, длинная подпись и видео. Никаких новых реальных
эпизодов от имени автора эти фикстуры не создают.

Офлайн-тесты: часовая граница месяца, 0/1/8/9/23 истории, разные годы,
смешанная и месячная пагинация без дублей, RSS, escaping,
отсутствие draft/future в production, повторяемость сортировки,
пагинация API без продвижения, archive/pinned/active без дублей,
.part, FloodWait, обновление file reference, недоступный источник,
повторный импорт, защита редакторского текста и EXIF-производные.
Браузерная проверка: 360/768/1280px, Back/Forward/Escape, фокус,
прямой permalink, отсутствие JS, видео и длинные подписи.

Доступ к реальному Telegram проверяется отдельно; успешные фикстуры
не означают, что аккаунт подключён или весь архив выгружен.
Порядок локального входа и работы — в [TELEGRAM-STORIES.md](TELEGRAM-STORIES.md).

Браузерные сценарии сохранены в `tests/browser_stories.py` и
`tests/browser_stories_extra.py`. Для их запуска в текущей рабочей среде:
`tools/route-generator/.venv/bin/python tests/browser_stories.py`
и аналогично для второго файла (эта локальная среда уже содержит Selenium).
В CI выполняются 25 тестов unittest; браузерные сценарии запускаются локально.

## Первый отобранный набор

70 историй, 107 кадров (98 фотографий, 9 видео), 17 месяцев. Состав
определён итоговым selection.json автора, включая возвращённые им
альтернативные кадры. Авторские подписи и порядок кадров сохранены.
Даты — время исходных публикаций, а не обязательно время съёмки.
